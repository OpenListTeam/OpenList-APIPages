# 前端源码导航

> **上级索引 / 被引用自**：[Token 授权前端](../README.md)

| 文件或目录 | 用途 |
| --- | --- |
| `main.tsx`、`App.tsx` | 应用初始化及页面入口 |
| `index.css` | 全局样式及响应式布局 |
| `pages/` | Token 授权、刷新和回调结果页面 |
| `components/` | 页头、页脚、凭据展示和授权弹窗等界面组件 |
| [i18n/](i18n/README.md) | 语言注册、切换及翻译资源 |
| `lib/` | API、回调数据解析、剪贴板和网盘辅助方法 |
| `theme/` | 明暗主题上下文 |

页面文案使用现有 i18n 资源，不把应用密钥、令牌或真实回调结果写入源码、截图或验证记录。
